# 🚀 CVPilot

### AI-Powered CV Builder & Review Platform

CVPilot is a web-based platform that helps users **create professional CVs, learn how to improve them, and receive AI-powered feedback**.

🔗 **GitHub Repository:** [CVPilot](https://github.com/SetayeshAmini/CVPilot)

🔗 **AI Review Backend:** [cvpilot-1.onrender.com](https://cvpilot-1.onrender.com)

## ✨ Features

- 🤖 **AI CV Review** — Analyzes CV content and provides personalized feedback.
- 📄 **CV Builder** — Helps users create a structured and professional CV.
- 📚 **CV Guide** — Provides useful tips and guidance for creating a stronger CV.
- 🏠 **Home Page** — Introduces CVPilot and guides users to its main features.
- 🎨 **Modern UI** — Includes responsive design, logo, footer, and loading animations.
